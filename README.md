# Streamlit Learning Examples

A collection of beginner-friendly Streamlit applications demonstrating common interface elements, media, and CSV data display.

## Contents

| File | Description |
| --- | --- |
| `chapter-1.py` | Basic page text and a language-selection dropdown. |
| `chapter-2.py` | Button, text input, number input, and radio-button examples. |
| `chapter-3.py` | Displays the included puppy image. |
| `chapter-4.py` | Slider callbacks, session state, text fields, date, and time inputs. |
| `chapter-5.py` | Loads and displays the included housing dataset as a dataframe and table. |
| `Eg.py` | A combined starter app with button, checkbox, slider, and CSV upload examples. |
| `Housing.csv` | Housing-price dataset used by `chapter-5.py` (545 records). |
| `image.jpg` | Image used by `chapter-3.py`. |
| `Streamlit.ipynb` | Jupyter notebook included with the original project. |

## Requirements

- Python 3.9 or later
- Streamlit
- pandas

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run an example

Open a terminal in this folder and start any application. For example:

```bash
streamlit run chapter-1.py
```

Try another example by replacing `chapter-1.py` with a different Python filename, such as `chapter-5.py` or `Eg.py`.
